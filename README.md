# 🎴 抽拉故事卡 · 纸套排版小工具

给 **8～11 岁孩子和家长** 一起做“抽拉故事卡”的**纯前端离线**应用：
孩子把 2～6 幕故事、每幕 1～3 张短句牌录进去，给每张牌挑允许出现的窗口，
程序会**联合搜索**纸套窗口列、各幕停点与每张牌的窗口分配，保证：

- 拉到某一幕的停点时，**当前幕全部牌同时、分别**出现在选定窗口里；
- **其他幕的句子不会从任何窗口提前（或滞后）露出来**；
- **两张牌不会印在同一个印刷槽**；
- 每张牌只印一次；第一幕停点固定为 0，其余停点从 1～12 严格递增。

技术栈：**TypeScript + Svelte 4 + Vite + SVG + Vitest + Playwright**。
全程无外部请求、无统计上报、无 CDN，断网可用。

---

## 手工玩法与数学规则（给家长）

- 纸套有 **6～12 个从零编号的列**，上面挖 **1～3 个单格窗口**，窗口所在列号互不相同。
- 每张牌固定在条带上，印刷槽：`印刷槽 = 本幕停点 + 窗口列号`。
- 每张牌给出自己的**允许窗口集合**（可只允许一个，也可允许多个）。
- 一张牌若放在某窗口，会在**别的幕停点**落进某个窗口列，就算“提前/滞后露出台词”，禁止。
- 搜索目标依次最小化：
  1. **纸套列数 + 最后停点**；
  2. **最大相邻停点差**（让抽拉距离尽量均匀）；
  3. 按幕、牌录入顺序排列的 **(停点, 窗口列) 数值序列字典序**最小（并列时结果确定、可复现）。
- 停点和窗口必须**一起联合搜索**：先贪心地定死前一幕往往会把后面的幕逼进死路。

如果怎么都摆不下（哪怕纸套放宽到 12 列也无解），程序返回
**最短不可行幕前缀**，并给出一个最接近成功的取证现场，逐张牌说明：
放到哪个窗口、印到哪个槽、在第几幕的哪个停点从哪一列露出，或和哪张牌同槽。


## 页面与功能

- **录入区**：窗口数量（1～3）、2～6 幕、每幕 1～3 张牌；每张牌写短句（≤24 字）、
  勾选允许窗口。任何改动都会**自动保存草稿到浏览器本地**并**立即清除旧校样**。
- **校样区（有解）**：
  - 最优列数、窗口列、停点与三项指标；
  - **SVG 联动图**：纸套、窗口、条带上的牌、每幕停点刻线；
    停点圆点可用鼠标/触摸**拖动**，或键盘 ←/→ 微调，实时标出“露底/撞槽”的红色冲突；
  - 每幕“窗口 → 印刷槽”明细表。
- **校样区（无解）**：最短不可行幕前缀 + SVG 取证现场 + 逐牌冲突说明（适龄措辞）。
- **打印制作页**：隐藏的同源 `srcdoc` iframe 调起浏览器打印，含
  - 纸套页：外框**裁切线角标**、窗口挖空虚线、上下**粘贴区**、列号；
  - 条带页：逐槽刻度、每张牌的印刷位置、起点**粘贴区**、全部**停点刻线**。
  - 打印帧样式为黑白友好，A4 横向，两页。
- **草稿恢复**：刷新/重开后自动恢复上次内容并显示温和提示条；清空浏览器站点数据即重置。

错误提示面向孩子（如“第 2 幕第 1 张牌还没有写句子”），
不会出现 `undefined`、堆栈或技术异常字样（有专门测试守护）。

### 求解器关键化简

固定（窗口列、停点向量）后：

1. 一张牌放在“幕 a、窗口 w”会不会在别的停点露出，**只与 (a, w) 有关**，
   可先算出每个“幕 × 窗口”的露出预算；
2. 不同幕的两张牌若印刷槽相同，则在彼此停点都正好落在窗口列上，必构成露出——
   所以“不露”自动排除所有跨幕撞槽；
3. 同幕牌槽位 = 同一停点 + 互异的窗口列，于是同幕只需在 ≤3 个窗口上做互异匹配。

每幕用牌录入顺序、窗口编号升序回溯，第一个解即字典序最小；
外层按“列数 → 窗口列组合 → 末停点 → 停点向量”有序枚举并按主键剪枝，
最坏输入（6 幕 × 3 牌）也在约 1.5 秒内完成。

## 离线与无固定答案说明

- 代码与依赖中**没有任何运行时外部 URL / 字体 / 统计 / CDN 请求**；
  `npm ci` 与 `npx playwright install` 仅是开发期下载。
- 程序**不内置任何故事答案**：所有结果都由孩子输入经搜索实时算出，
  单元测试里的期望值来自独立的暴力参照实现而非硬编码业务答案。
